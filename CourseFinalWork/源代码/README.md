# CityGo 城市旅行介绍网站

> Web 前端开发课程设计项目。CityGo 以“城市 · 风景 · 美食 · 路线”为核心，提供城市推荐、分类浏览、城市详情、用户登录注册、心愿单收藏、旅行日记和旅行足迹地图等功能。

## 1. 项目简介

CityGo 是一个纯前端城市旅行介绍网站，面向城市自由行、短途旅行爱好者和城市文化探索者。用户可以通过首页浏览热门城市，在分类页筛选不同类型的城市，在详情页了解城市景点、美食、文化、路线和出行建议，也可以登录后收藏心愿城市、记录旅行日记，并在地图上查看自己的旅行足迹。

项目采用 HTML5、CSS3 和 JavaScript 编写，不依赖后端服务器。用户信息、登录状态、心愿单和旅行日记等数据主要通过浏览器 `localStorage` 进行模拟存储，便于课程展示、本地运行和功能演示。

## 2. 主要功能

### 2.1 首页展示

首页文件为 `index.html`，主要功能包括：

- 顶部统一导航栏
- 城市风景主视觉轮播图
- 轮播图上一张、下一张和指示点切换
- 自动轮播，当前版本自动切换时间为 3 秒
- 风景视频展示区
- 热门城市推荐卡片
- 城市搜索与分类筛选
- 分页展示城市卡片
- 旅行路线切换
- 拖拽城市卡片加入心愿单
- 右侧推荐栏和浮动广告
- 页脚版权与项目信息展示

### 2.2 分类浏览

分类浏览页文件为 `category.html`，用于按照城市类型展示城市卡片。页面支持以下分类：

- 全部城市
- 美食城市
- 自然风光
- 历史文化
- 现代都市

每张城市卡片包含城市图片、城市名称、简介、标签以及操作按钮。用户可以查看详情、进入详情页或加入心愿单。

### 2.3 城市详情

城市详情页文件为 `city.html`，主要逻辑由 `city.js` 实现。页面通过 URL 参数动态加载城市数据，例如：

```text
city.html?id=hangzhou
city.html?id=chengdu
city.html?id=beijing
```

详情页展示内容包括：

- 城市名称和简介
- 城市主图与背景图
- 代表景点
- 特色美食
- 文化特色
- 推荐季节
- 推荐旅行路线
- 出行提示
- 城市宣传片视频预留区

### 2.4 登录与注册

登录页为 `login.html`，注册页为 `register.html`，主要逻辑由 `auth.js` 实现。

功能包括：

- 预置账号登录
- 新用户注册
- 用户名、邮箱、密码等基础校验
- 密码一致性检查
- 登录成功后写入当前用户状态
- 注册用户保存到 `localStorage`
- 登录后自动跳转或刷新用户状态

预置账号位于 `accounts.json`，可用于测试：

|---|---|---|
| travel01 | Tgo123456 | 旅行记录展示账号 |
| cityfan | City2026 | 城市夜景与文化路线账号 |
| foodlover | Food8888 | 美食旅行账号 |
| scenery | View6666 | 自然风光账号 |
| demo | demo123456 | 课程演示账号 |

### 2.5 用户中心

用户中心页面为 `user.html`，主要逻辑由 `user.js` 实现。

功能包括：

- 读取当前登录用户信息
- 展示头像、用户名、邮箱、手机号、性别、生日、所在城市、注册日期等资料
- 展示心愿单数量
- 提供快捷入口
- 未登录时显示登录提示
- 支持退出登录

### 2.6 旅行心愿单

心愿单页面为 `wishlist.html`，主要逻辑由 `wishlist.js` 实现。

功能包括：

- 展示当前用户收藏的城市
- 支持从首页、分类页、城市弹窗中加入心愿单
- 支持移除单个收藏
- 支持清空全部收藏
- 未登录时提示先登录
- 通过用户名隔离不同用户的心愿单数据

### 2.7 联系我们

联系我们页面为 `contact.html`，用于展示留言反馈表单。

表单字段包括：

- 姓名
- 性别
- 年龄范围
- 邮箱
- 电话号码
- 留言内容

页面会对必填项、邮箱格式、电话格式等进行基础验证，并在提交后回显用户输入内容。

### 2.8 关于网站与 Canvas 图表

关于网站页面为 `about.html`，用于介绍项目功能、设计亮点和技术说明。该页面使用 HTML5 Canvas 绘制热门城市旅行热度柱状图，体现图形绘制能力。

### 2.9 旅行日记

旅行日记页面为 `diary.html`，主要逻辑由 `diary.js` 实现。

功能包括：

- 登录用户查看个人旅行日记
- 新增旅行日记
- 编辑和删除日记
- 日记标题、城市、正文内容编辑
- 正文中插入图片，实现图文混排
- 手动选择封面图
- 未手动选择封面时自动使用正文第一张图片作为封面
- 查看日记详情弹窗
- 旅途影像册展示日记中的图片与视频封面
- 3D 旋转影像卡片效果
- 根据 URL 参数筛选某个城市的日记，例如：

```text
diary.html?city=hangzhou
```

### 2.10 旅行足迹

旅行足迹页面为 `footprint.html`，主要逻辑由 `footprint.js` 实现。

功能包括：

- 读取当前用户心愿单数据
- 读取当前用户旅行日记数据
- 自动提取用户涉及的城市
- 使用 Leaflet 地图生成城市标点
- 点击地图标点跳转到对应城市的旅行日记
- 展示已探索城市列表

该页面使用 Leaflet 和在线地图瓦片，因此需要网络环境才能正常加载地图资源。

## 5. 运行方式

### 5.1 直接打开方式

本项目为纯静态前端项目，最简单的运行方式是直接双击打开：

```text
index.html
```

适合快速查看页面布局和基础效果。

### 5.2 推荐运行方式：使用本地服务器

由于项目中使用了 `accounts.json`、图片视频资源和部分浏览器存储功能，推荐使用本地静态服务器运行。

如果电脑已安装 Python，可以在项目根目录打开命令行，执行：

```bash
python -m http.server 8080
```

然后在浏览器访问：

```text
http://localhost:8080/index.html
```

如果使用 VS Code，也可以安装 Live Server 插件，然后右键 `index.html`，选择 `Open with Live Server`。

### 5.3 地图页面运行说明

`footprint.html` 使用 Leaflet 和在线地图瓦片，访问该页面时需要网络连接。如果网络不可用，地图底图可能无法加载，但页面其他结构仍可显示。

## 7. 数据存储说明

项目没有连接真实数据库，主要使用浏览器 `localStorage` 模拟数据持久化。

常用存储键如下：

| localStorage 键 | 说明 |
|---|---|
| `citygo_users` | 注册用户列表 |
| `citygo_current_user` | 当前登录用户 |
| `citygo_wishlist_用户名` | 指定用户的心愿单数据 |
| `citygo_diary_用户名` | 指定用户的旅行日记数据 |
| `citygo_preset_version_用户名` | 预置数据版本标记 |

如果需要恢复初始状态，可以在浏览器开发者工具中清除 Local Storage，或执行：

```javascript
localStorage.clear();
```

注意：执行该语句会清空当前网站在浏览器中保存的所有本地数据，包括注册用户、登录状态、心愿单和旅行日记。

## 11. 新增城市方法

如果需要新增一个城市，可以按照以下步骤操作：

1. 在 `script.js` 的城市数据数组中新增城市基本信息。
2. 在 `category.html` 或相关分类数据中补充城市分类信息。
3. 在 `city.js` 中新增城市详情数据，包括景点、美食、路线、季节和提示。
4. 在 `footprint.js` 中补充城市坐标，保证旅行足迹地图能显示该城市。
5. 在 `resource/images/城市id/` 下添加城市图片。
6. 检查首页、分类页、详情页、心愿单和足迹页显示是否正常。

城市 `id` 建议使用英文小写，例如：

```text
hangzhou
chengdu
beijing
shanghai
```

## 12. 常见问题

### 12.1 图片或视频无法显示

可能原因：

- `resource/` 目录缺失
- 图片文件名与代码中引用路径不一致
- 图片扩展名不一致，例如代码引用 `.jpg`，实际文件是 `.svg`
- 视频文件体积较大或浏览器不支持当前格式

解决方法：

- 检查资源文件是否存在
- 保证文件名、目录名和扩展名完全一致
- 浏览器控制台查看 404 报错路径

### 12.2 登录后页面仍显示未登录

可能原因：

- 浏览器禁用了 localStorage
- 页面不是同一域名或同一端口打开
- 手动清除了浏览器本地存储
- `citygo_current_user` 数据格式异常

解决方法：

- 使用本地服务器统一访问项目
- 清除 Local Storage 后重新登录
- 检查控制台是否有 JavaScript 报错

### 12.3 旅行足迹地图无法显示

可能原因：

- 网络不可用
- Leaflet CDN 加载失败
- 在线地图瓦片加载失败

解决方法：

- 保证电脑可以联网
- 检查浏览器控制台网络请求
- 将 Leaflet 资源下载到本地后改成本地引用

### 12.4 预置日记或心愿单没有出现

可能原因：

- 当前登录用户不是预置账号
- 本地已有旧版本数据
- `seed-data.js` 未被对应页面引入

解决方法：

- 使用 `demo`、`travel01` 等预置账号登录
- 清除 Local Storage 后重新登录
- 检查页面是否引入 `seed-data.js`

### 12.5 页面样式错乱

可能原因：

- CSS 文件路径错误
- 浏览器缓存未刷新
- 文件夹结构被移动

解决方法：

- 保持原项目目录结构
- 使用 `Ctrl + F5` 强制刷新
- 检查 HTML 中 CSS 引入路径是否正确

## 13. 开发与调试建议

- 使用 Elements 面板检查 HTML 结构和 CSS 样式
- 使用 Console 面板查看 JavaScript 报错
- 使用 Network 面板检查图片、视频、JSON、CDN 是否加载成功
- 使用 Application 面板查看 localStorage 中的数据

## 14. 项目特点

- 页面结构完整，覆盖首页、分类页、详情页、登录注册、用户中心、心愿单、联系我们和关于网站等页面。

- 旅行足迹通过地图展示用户涉及城市，形成“发现城市—收藏城市—记录日记—生成足迹”的交互闭环。
